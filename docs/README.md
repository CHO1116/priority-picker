# 📦 Priority Picker — 주문 우선순위 기반 물류 피킹 로봇 셀

> 뒤섞인 입고 상품(색상 큐브)을 3D 비전으로 인식하고, **긴급 주문부터 · 집기 쉬운 것부터 · 가까운 것부터** 순서로 로봇팔이 출고 박스에 담는 소형 풀필먼트(Fulfillment) 셀

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **프로젝트 명** | Priority Picker (주문 우선순위 기반 물류 피킹 시스템) |
| **프로젝트 목적** | 물류센터의 "주문 피킹" 공정을 축소 재현하여, 비전 인식 + 우선순위 작업 계획 + 로봇 픽앤플레이스를 하나의 자동화 셀로 통합한다. |
| **프로젝트 기간** | 2026.11.09 ~ 2026.11.15 (1주) |
| **배경** | 이커머스 물량 증가로 물류센터는 인력 부족과 피킹 오류(오배송) 비용 문제를 겪고 있다. 특히 당일·새벽 배송처럼 **마감 시간이 다른 주문이 섞여 있을 때**, 어떤 상품을 먼저 집을지가 출고 성공률을 좌우한다. 실제로 대형 물류 기업들이 로봇 피킹 시스템을 도입하는 추세다. |
| **목표** | ① 색상 큐브 4종을 3D 위치와 함께 인식 ② 주문(긴급/일반)에 따라 피킹 순서 자동 결정 ③ 파지 실패·인식 불가·재고 부족 상황에서도 멈추지 않고 동작 ④ 무작위 순서 대비 처리 시간 단축을 정량적으로 검증 |

### 현실 매핑

| 현실 물류센터 | 우리 프로젝트 |
|---|---|
| 상품(SKU) | 색상 큐브 (빨강·파랑·초록·노랑) |
| 입고 적재 구역 | 큐브가 흩어진 작업대 |
| 출고 박스 (주문별) | 박스 A (긴급 주문) / 박스 B (일반 주문) |
| 예외 처리 구역 | 보류함 (주문에 없는 상품, 인식 불확실 물체) |
| WMS (창고관리시스템) 주문 | Order Manager 노드에 주문 입력 |
| 피킹 작업자 / 로봇 | Doosan E0509 + RH-P12-RN-A 그리퍼 |

## 🎬 시나리오

1. **주문 입력**: 작업자가 주문을 등록한다.
   - 주문 #1 (🚨 긴급·당일배송): 빨강 2, 파랑 1 → 박스 A
   - 주문 #2 (일반): 초록 2, 노랑 1 → 박스 B
2. **스캔**: 로봇이 스캔 자세로 이동하고, RealSense가 작업대 전체를 촬영해 큐브의 색상·3D 위치·회전각을 검출한다.
3. **작업 계획**: 아래 기준으로 다음에 집을 큐브 1개를 선택한다.
   1. **업무 우선순위**: 긴급 주문에 필요한 색상 먼저
   2. **파지 가능성**: 주변 큐브와 간격이 충분해 그리퍼가 들어갈 수 있는 것 먼저
   3. **효율**: 현재 그리퍼 위치에서 가장 가까운 것 먼저
4. **피킹 → 적재**: 큐브를 집어 해당 주문 박스에 놓는다.
5. **재스캔**: 1개 처리할 때마다 다시 스캔한다 (집는 도중 다른 큐브가 밀릴 수 있으므로).
6. **예외 처리**
   - 파지 실패 (그리퍼가 끝까지 닫힘) → 재스캔 후 최대 2회 재시도, 이후 건너뜀
   - 주문에 없는 색 / 신뢰도 낮은 물체 → 모든 주문 완료 후 보류함으로 이동
   - 재고 부족 → "빨강 1개 부족" 알림, 해당 주문은 `부분 완료` 처리
7. **완료 리포트**: 주문별 처리 시간, 성공/실패 수, 총 이동 거리를 출력한다.

## ⭐ 주요 기능 (3개)

1. **3D 큐브 인식**: RGB-D 영상에서 색상 분류 + 로봇 좌표계 기준 3D 위치·회전각 추정
2. **주문 우선순위 작업 계획**: 긴급도 → 파지 가능성 → 거리 3단계 기준으로 피킹 순서 결정
3. **무중단 픽앤플레이스**: 파지 실패·인식 불가·재고 부족 시에도 멈추지 않는 예외 처리
