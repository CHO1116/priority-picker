# 🗓️ 일정 및 역할 분담 (7일 · 3인)

## 핵심 원칙

1. **첫날부터 셋이 동시에 출발한다.** 노드끼리 주고받는 메시지 형식(인터페이스)을 Day 1에 확정하고, 각자 **가짜 데이터**로 개발한다. 실제 로봇·카메라가 없어도 비전/계획/제어를 따로 진행할 수 있다.
2. **"한 개 집기"를 Day 3까지 무조건 성공시킨다.** 이게 안 되면 나머지는 의미가 없다. 가장 위험한 작업(캘리브레이션)을 앞에 배치했다.
3. **Day 5 저녁에 기능 개발을 멈춘다(Feature Freeze).** Day 6은 시연 영상 촬영과 발표 준비 전용이다.
4. **매일 시작 10분 스탠드업 + 회의록.** 평가 항목(협업)이므로 짧게라도 꼭 남긴다.

## 간이 캘리브레이션 방법 (Day 3)

정식 Hand-Eye 캘리브레이션이 시간 안에 어렵다면 아래 방법이 가장 빠릅니다.

1. 로봇을 **스캔 자세**로 이동 (카메라가 고정이면 생략)
2. 작업대에 큐브(또는 마커)를 놓고, 비전으로 **카메라 좌표** `(Xc, Yc, Zc)` 기록
3. 로봇 TCP를 손으로 그 큐브 중심에 맞춰 이동(직접 교시)하고 **로봇 좌표** `(Xb, Yb, Zb)` 기록
4. 서로 다른 위치에서 **8곳 이상** 반복
5. 두 점 묶음 사이의 강체 변환을 SVD(Kabsch 알고리즘)로 계산 → `T_base_camera` 저장
6. 새로운 위치에서 검증, 오차 ±10mm 이내면 통과

> 스캔 자세를 매번 같은 관절값으로 이동하면, 손목 카메라라도 이 변환을 고정값으로 쓸 수 있다.
