# 📄 기능 명세서

**우선순위 표기**
- **P0**: 필수. 없으면 시연이 안 됨. Day 4까지 완료
- **P1**: 평가 핵심(예외 처리, 정량 결과). Day 5까지 완료
- **P2**: 시간이 남으면. 발표에서는 "확장 계획"으로 소개 가능

---

## 0. 전제 조건 (범위 제한)

1주 일정에 맞추기 위해 다음을 전제로 합니다. 발표에서 "환경 가정"으로 명시하면 요구사항의 현실성 평가에 오히려 도움이 됩니다.

| 항목 | 가정 |
|---|---|
| 물체 | 한 변 약 **5cm** 정육면체, 4색 (빨강·파랑·초록·노랑), 각 2~3개 |
| 배치 | 작업대 위 한 층으로 흩어 놓음 (쌓기는 P2) |
| 카메라 | 로봇의 **고정 스캔 자세에서 위를 내려다보는 시점** (손목 장착 시 스캔 자세 1곳 고정) |
| 박스 위치 | 박스 A, 박스 B, 보류함의 좌표는 티칭으로 고정 |
| 조명 | 실내 조명. 시연 전 색상 임계값 재조정 절차 포함 |
| 주문 입력 | 터미널(CLI) 또는 YAML 파일. GUI는 P2 |

## F1. 3D 큐브 인식 (담당: 이준희)

| ID | 요구사항 | 우선순위 | 완료 기준 |
|---|---|---|---|
| F1-1 | RealSense 컬러·깊이 영상을 정렬하여 수신한다 | P0 | `ros2 topic hz`로 15Hz 이상 확인 |
| F1-2 | HSV 색상 범위로 4색 큐브 영역을 검출한다 | P0 | 10회 촬영 중 9회 이상 전 큐브 정확 분류 |
| F1-3 | 큐브 윗면 중심 픽셀 + 깊이로 카메라 좌표 3D 위치를 계산한다 | P0 | 자로 잰 실제 위치와 오차 ±10mm 이내 |
| F1-4 | 캘리브레이션 행렬로 로봇 base 좌표로 변환한다 | P0 | 로봇 TCP를 큐브 위로 보냈을 때 중심 오차 ±10mm 이내 |
| F1-5 | 큐브 회전각(yaw)을 `minAreaRect`로 추정한다 | P0 | 그리퍼가 큐브 면과 평행하게 접근 |
| F1-6 | 주변 큐브와의 최소 간격(`min_gap`)을 계산한다 | P1 | 붙어 있는 큐브는 `min_gap`이 작게 나옴 |
| F1-7 | 면적·깊이가 이상한 물체는 `UNKNOWN`으로 분류한다 | P1 | 큐브가 아닌 물체를 놓으면 UNKNOWN 출력 |
| F1-8 | 겹쳐 쌓인 큐브는 깊이로 위의 것만 후보로 낸다 | P2 | 2단 적층 시 위 큐브만 검출 |

## F2. 주문 우선순위 작업 계획 (담당: 조영준)

| ID | 요구사항 | 우선순위 | 완료 기준 |
|---|---|---|---|
| F2-1 | 주문(색상별 수량, 긴급도, 박스)을 입력받아 관리한다 | P0 | 주문 2건 등록, 진행 상태 출력 |
| F2-2 | 긴급 → 일반 순으로 필요한 색상의 큐브를 선택한다 | P0 | 긴급 주문 물량이 항상 먼저 처리됨 |
| F2-3 | 같은 우선순위 안에서는 현재 그리퍼 위치에서 가까운 큐브를 선택한다 | P0 | 로그에서 거리순 선택 확인 |
| F2-4 | `min_gap`이 부족한 큐브는 이번 사이클에서 제외한다 | P1 | 붙은 큐브를 건너뛰고 나중에 처리 |
| F2-5 | 필요한 색상이 없으면 재고 부족 알림 후 부분 완료 처리한다 | P1 | 큐브를 1개 빼 두고 실행 시 알림 출력, 정지 없음 |
| F2-6 | 주문에 없는 색·UNKNOWN 물체는 마지막에 보류함으로 옮긴다 | P1 | 보류함에 정확히 이동 |
| F2-7 | 완료 리포트(주문별 시간·성공/실패·이동 거리)를 CSV로 저장한다 | P1 | `results/*.csv` 생성 |
| F2-8 | 비교 모드: 무작위 순서 / 색상 순서 / 우리 방식 선택 실행 | P1 | 3가지 모드 각 3회 측정 표 완성 |

## F3. 무중단 픽앤플레이스 (담당: 류창표)

| ID | 요구사항 | 우선순위 | 완료 기준 |
|---|---|---|---|
| F3-1 | 스캔 자세, 홈 자세, 박스 3곳 위 자세를 티칭·저장한다 | P0 | 설정 파일(YAML)에 좌표 저장 |
| F3-2 | 접근(위 100mm) → 하강 → 파지 → 상승 → 이동 → 놓기 순서로 동작한다 | P0 | 단일 큐브 10회 중 9회 이상 성공 |
| F3-3 | 큐브 yaw에 맞춰 그리퍼를 회전한다 | P0 | 45° 돌아간 큐브도 파지 성공 |
| F3-4 | 그리퍼를 열고 닫고, 현재 벌림 폭을 읽는다 | P0 | 열기/닫기/폭 읽기 함수 동작 |
| F3-5 | 닫은 뒤 벌림 폭이 거의 0이면 **파지 실패**로 판정한다 | P1 | 큐브 없이 집으면 GRASP_FAIL 반환 |
| F3-6 | 파지 실패 시 안전 높이로 복귀 후 결과를 보고한다 | P1 | 실패 후에도 다음 동작 정상 진행 |
| F3-7 | 작업 영역 밖 좌표 요청은 실행하지 않고 오류를 반환한다 | P1 | 범위 밖 좌표 → MOTION_ERROR, 로봇 미동작 |
| F3-8 | 붙어 있는 큐브를 밀어서 떼어내는 동작 | P2 | — |

|---|---|
