## 예상 질문 (Q&A 대비)

- **캘리브레이션 오차는 어떻게 검증했나?** 측정에 쓰지 않은 위치에 큐브를 놓고, TCP를 보내서 중심 오차를 잰다 (목표 ±10mm).
- **작업 도중 긴급 주문이 새로 들어오면?** 1개를 처리할 때마다 재스캔하고 주문 목록을 다시 읽으므로, 다음 사이클부터 반영된다.
- **왜 색상 큐브인가?** 상품(SKU)을 단순화한 것이다. 인식부만 바꾸면 실제 상품으로 확장할 수 있고, 우선순위 로직은 그대로 쓴다.
- **min_gap 기준값은 어떻게 정했나?** 그리퍼 손가락 두께와 벌림 여유를 기준으로 정하고, 현장에서 조정한다.
